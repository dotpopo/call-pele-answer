学习率决定每一步沿梯度走多远。太小，收敛慢；太大，损失来回震荡甚至发散。先用 1e-3 起步，再按验证损失调整。

## 一次更新在做什么

```mermaid
flowchart LR
  A[取一批数据] --> B[前向计算损失]
  B --> C[反向求梯度]
  C --> D["参数 -= 学习率 × 梯度"]
  D --> A
```

学习率只出现在第 4 步。它不改变方向，只改变步长。

## 三种调度策略

| 策略 | 做法 | 适合 | 风险 |
|---|---|---|---|
| 固定 | 全程同一个值 | ok 小模型、快速试验 | warn 后期震荡 |
| 阶梯衰减 | 每 N 轮乘 0.1 | ok 图像分类 | warn 需要手调 N |
| 预热 + 余弦 | 先升后按余弦降 | ok 大模型、Transformer | ok 最稳 |

## 找学习率的步骤

```steps title="LR range test" ms=2600
1. 从 1e-7 开始训练一小段。
---
2. 每一步把学习率乘一个固定倍数。
---
3. 记录每一步的损失。
---
4. 选损失下降最快处，再往小取十分之一。

~~~mermaid
flowchart LR
  S[1e-7] --> U[指数增大] --> R[记录损失] --> P[选最陡处 ÷10]
~~~
```
