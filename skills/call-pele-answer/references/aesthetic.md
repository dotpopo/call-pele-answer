# 设计原则

页面的默认样子：一页安静的笔记，图和正文共用一套颜色变量，窄屏重排而不是缩小。下面是原则，以及模板怎么落地。

## 七条原则

1. **墨在纸上（Ink on paper）。** 暖白纸色 + 近黑墨色，颜色只用来表达意义。默认是一页笔记，不是控制台、不是仪表盘。
   → 模板：纸色 `#FFFCF0`、墨色 `#100F0F`；单栏、约 44rem 阅读宽度；块之间只用一条细线分隔。

2. **一套令牌，处处通用。** 图不是另一种风格的贴图：节点底色、线条、字体都读页面的同一组变量。换主题时图跟着变，**不重新渲染**。
   → 模板：`.pele { --pele-surface: var(--pe-surface) … }`，正文和图共用 `--pe-*`。深色模式只是换一组变量。

3. **适应，而不是缩放（Adapt, don't scale）。** 窄屏时重新排版（宽 LR 流程图在 640px 以下改成竖排、标签换行），而不是把整张图缩成看不清的小图。
   → 模板：CLI 对每张图渲染两次（maxWidth 880 / 360），CSS 在 640px 切换。图本来就窄时只保留一份。

4. **平放、安静。** 静止状态没有阴影、渐变、发光。层次靠细边框（1px）、底色深浅、字重。圆角 4px。
   → 模板：卡片只有 1px 边框；按钮是描边；强调色只出现在链接、焦点、进度和当前标签。

5. **颜色稀缺且有语义。** 一个强调色（蓝）负责“看这里”；红=风险/错误，绿=通过，黄=注意；8 个系列色只给类别和数据系列。不为“活泼”加颜色。
   → 模板：`ok/no/warn` 徽章、callout 左边线；8 个系列色映射到 `--pele-series-1…8`。

6. **小而快，无需运行时。** 产物是一个文件；图在构建时就是 SVG，关掉 JavaScript 也能读完全部内容。JS 只增强交互（滑块、标签、分步、主题切换）。
   → 模板：CSP 禁止外部请求；无 CDN、无网络字体；`nojs` 时所有分步/标签内容展开显示；打印时也展开。

7. **文件高于应用（File over app）。** 源文本是唯一真相，可读、可改、可迁移。Mermaid 文本即使不渲染也能看懂。
   → 模板：页面内嵌 Markdown 原稿（`#pe-source`），页脚可复制给 Agent 修改；`pe patch` 直接从页面里取原稿改一块。

## 字体

- 正文与图：系统无衬线 + 中文黑体（`-apple-system, Inter, PingFang SC, Microsoft YaHei, Noto Sans CJK SC`）。图和正文同一字体，渲染器按这个字体测量标签宽度。
- 等宽只用于代码、编号、元信息（日期、页眉键值、刻度）。
- 层级靠字号与字重（650），不引入展示字体。

## 令牌（浅色 / 深色）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--pe-paper` | #FFFCF0 | #100F0F | 页面与图背景 |
| `--pe-ink` | #100F0F | #CECDC3 | 正文、线条 |
| `--pe-muted` | #6F6E69 | #878580 | 次要文字 |
| `--pe-border` | #CECDC3 | #403E3C | 分隔线、边框 |
| `--pe-surface` | #F2F0E5 | #1C1B1A | 节点、代码底色 |
| `--pe-surface-2` | #E6E4D9 | #282726 | 分组底色 |
| `--pe-blue` | #205EA6 | #4385BE | 强调（唯一） |
| `--pe-red` | #AF3029 | #D14D41 | 风险、错误 |
| `--pe-green` | #66800B | #879A39 | 通过 |
| `--pe-yellow` | #AD8301 | #D0A215 | 注意 |

另有 orange / cyan / purple / magenta 只作系列色。

## 不要

- 不要卡片网格、玻璃拟态、渐变文字、彩色大标题、装饰图标。
- 不要在 Mermaid 里写固定颜色（`style fill:#…`），它不随主题切换。
- 不要为了“不空”加块或加图。
- 不要用动画表达静态图里没有的关系；动画必须能暂停、能单步，静止帧里含义完整。

## 调色器

默认每块自动上色（`color: plain` 恢复素色）；读者还能自己调：调色器让读者给任一组件换一个色板（浅 / 中 / 深三档的糖果色），或切换整页风格。只换强调色和底色，墨色不动，所以再多颜色也不伤可读性。
