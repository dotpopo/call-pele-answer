# 页面上的调色器与批注

两者默认开启。关闭：稿件 `palette: off` / `annotate: off`，命令行 `--palette off` / `--annotate off`，环境变量 `PE_PALETTE=0` / `PE_ANNOTATE=0`，或配置 `"palette": false` / `"annotate": false`；稿件里写的优先。

## 组件编号

`lead`（导语）、`lead.1`（导语第 1 段）、`s2`（第 2 块整块）、`s2.1`（第 2 块第 1 个内容单元）。

## 调色器

页头「调色」：点选组件再点色板，只有它换色，图表跟着变；「页面」一行切整页风格（墨纸 / 暖纸 / 蓝图）。色板只换强调色和底色，正文墨色不变，对比度不受影响。

读者点「复制配色」得到一行：

```
palette: page=warm s2=tomato s3.1=cobalt s4.h~bg=mint s5.1.g3=tomato
```

键：`.h` 标题、`.pK` 段落、`.hd` 表头、`.rK` 行、`.rKcJ` 格、`.gK` 图形，`~bg` 表示背景。**读者发回这行时，原样放进稿件 front matter 再渲染，不改颜色。**

## 批注

每块左侧有 ✎，可选类型（疑问 / 建议 / 认可 / 顾虑）并写一句话，存在浏览器里。「复制给 Agent」得到：

```
## 对《标题》的批注
1. [建议] §02 三种问题类型 › “choice 从你定义的选项里选一个…”（s2.1）
   > 这里能举个例子吗
```

读者发回时，按编号找到块：疑问 → 在原块补解释；建议 → 照改；顾虑 → 核实后改或说明；认可 → 不动。只改被批注的块（`pe patch` 或改稿重渲染，未改的块走缓存）。

插件可加批注类型：`api.annotation({ name, label, color })`。
